# Dark Forest — Raincord iOS theme

`Forestry.json` has been updated from the legacy spec-2 manifest to Raincord spec 3 for the current iOS mobile build.

The iOS 27 compatibility update deliberately omits the `KEYBOARD` and `BACKGROUND_PRIMARY` semantic overrides. The remaining palette, fonts, background animation, author attribution, and optional Themes+ metadata are preserved.

## Install

Paste this URL into Raincord's theme installer:

```text
https://raw.githubusercontent.com/TaakoOfficial/Porsche.911/main/Forestry.json
```

Run `node validate-forestry.mjs` from the repository root to validate the manifest and iOS compatibility rules.
